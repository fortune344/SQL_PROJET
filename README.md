# Sales Management Database

Projet de base de données relationnelle développé avec SQL Server.

## Description

Cette base de données permet la gestion :

- des clients
- des produits
- des commandes
- des paiements
- des employés
- des stocks

## Compétences démontrées

- Modélisation relationnelle
- Clés primaires et étrangères
- Contraintes d'intégrité
- Requêtes SQL
- Jointures (JOIN)
- Agrégations (GROUP BY)
- Tri des données (ORDER BY)

## Structure

7 tables relationnelles reliées par des clés étrangères.
